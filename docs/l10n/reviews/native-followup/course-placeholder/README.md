# Instrument-course placeholder review

The live PaywallPlan.lessonsOutcome template receives the complete localized title of the first matching played-instrument course. Voice is excluded; Songs follows its corresponding instrument course. All 48 current templates and all 336 actual title values (seven per locale) were directly read and their grammatical composition assessed. The generated full renderings are preserved as reproducible examples, not as a claim of 336 on-device screenshots or separately displayed full-sentence reads.

Fourteen locale proposals repair accusative/locative/genitive or compound-stem assumptions, associative noun-class composition, and one related Chinese predicate that was too narrow for bowed instruments. The affected locales are cs, de, el, et, hr, is, lt, lv, mr, pl, sk, sl, zh-CN and zu. Thirty-four existing argument constructions are retained; valid analytic postpositions, noun adjacency, current compound stems and already quoted apposition are not globally rewritten.

Case-safe proposals put the unchanged course title before a colon. Reader register stays as defined by each glossary. The Chinese proposal changes only 弹奏 to generic 演奏 so violin/cello values remain natural. All 48 decisions preserve the one-%@ placeholder contract and record exact current-old/source/new hashes, all actual argument values and source/glossary bindings.

The Croatian register-only proposal is superseded by an addendum with both the exact current-old and exact prior-proposed value as explicit guards. Its frozen evidence is untouched. Romanian de plus the nominative course title is valid, so its separate te/cânți register proposal stays unchanged and is not a new case correction. Turkish already uses singular wording and a correct indefinite noun compound; no prior register proposal exists for this key. Slovenian uses the root-selected case-safe informal target.

This is bounded source-aware AI review of one template, not native-human certification, a universal UI semantic audit or device-layout verification. No live maps, code, glossary or store payloads were modified.

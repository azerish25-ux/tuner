## 1. Locale decisions
- Variant: Catalan (Catalonia).
- Address: tu; warm, direct teacher voice. Gender-neutral phrasing for an unknown reader. Buttons match existing table; instructions use natural imperatives. VoiceOver hints describe outcomes in the third person.
- Quotation: «…» for titles; controls unquoted; apostrophes follow existing controls, typographic ’ in new prose; single ellipsis … only.
- Spaces: ordinary single spaces; no leading/trailing spaces.
- Digits: ASCII 0–9; preserve every literal value and lesson digit group. Hz, BPM, ¢, XP, ms remain. Minute/second words follow ordinary local usage; abbreviations only when source abbreviates.
- Capitalization: sentence case; no English title case.
- Interface notes come from placeholders, never invented; lesson note letters and chord symbols remain English letter notation; never convert to solfège.
- Accidentals are distinct from tuner direction. sostingut / bemoll / doble sostingut / doble bemoll; direction massa agut / massa greu.
- Legal Settings path: Configuració › Compte d’Apple › Subscripcions. Apple feature labels follow shipped localized strings; Siri, Apple Watch, Game Center remain unchanged. Retain all subscription facts, cancellation windows and free-tier qualifications.
- Siri: natural spoken imperative, all ${applicationName} and other tokens intact; Next/Again/Slower use one shared control/command translation.

## 3. Course and song names
Instrument course titles match catalogue instrument names. Ear Training, Music Theory, Rhythm and Singing match their existing localized Learn titles; Songs must match the Songs tab. Originals and Standards & Classics use existing localized course titles. Instrument Songbook titles use the localized instrument plus the existing localized Songbook term. Established public-domain song titles use their established local titles; other traditional titles stay English. Timbre Originals retain existing localized lesson titles. Every prose mention and leaderboard uses the exact lesson title. Lyric credits preserve names and years and translate connecting prose. Sung lyrics remain unchanged.

## 4. Words that mislead
Tune as a verb means tuning, as a noun a melody. Sharp/flat on the tuner mean too high/low, not accidentals. Bar means measure; key means tonality. Pick means plectrum or plucking in music, choose in UI. Lock means a stable in-tune confirmation, not a padlock. Take is one recorded performance, not taking a lesson. Run means a practice streak or an uninterrupted passage, not running. Chart means an instrumental chord diagram/sheet unless progress statistics explicitly demand a graph. Intonation is context-dependent: the current literal app key `Intonation` labels the harmonic/stopped-note instrument-setup check; `Intonation over a drone` is a separate pitch-accuracy practice key. Generic lesson uses follow their own source context. Do not infer a blanket ban on saddle setup from the English word alone. Practice is musical practice. Feel is haptic vibration, not emotion. A challenge to a friend differs from the unit's final challenge lesson; preserve context.

### Terminology and shared contexts
- root of a chord: **fonamental**; home/tonic of a key: **tònica**. A literal root-position chord is **estat fonamental**.
- quarter/half/whole/eighth/sixteenth note: **negra / blanca / rodona / corxera / semicorxera**. Dot: **puntet**; dotted note: **nota amb puntet**. Beat duration: **pulsació**; numbered bar position: **temps** where more natural.
- major/minor third, fourth, fifth, sixth, seventh: **tercera major/menor, quarta, quinta, sisena, setena**. Finger ordinals: **primer, segon, tercer, quart dit**. Never confuse the current interval-only Second/Third/Fourth keys with explicit finger keys.
- scale degree: **grau**; major/minor pentatonic box: **posició pentatònica major/menor**; arpeggio: **arpegi**; triad: **tríada**; inversion: **inversió**; voicing: **disposició**; Dorian/Mixolydian: **dòric / mixolidi**.
- pluck/pick a string: **polsar**; fingerpick: **puntejar amb els dits**; fretboard: **diapasó**; hammer-on/pull-off: **lligat ascendent/descendent**; bend: **bend**; trill: **refilet**; rest stroke: **polsació recolzada**.
- palm muting: **apagat amb el palmell**; chunk: **rascat apagat**; scratch: **rascat sec**; backbeat: **backbeat** (independent-review override of author-stage contracop); turnaround: **enllaç de tornada**; walking bass: **baix caminant**; fill: **ornament**; hook/lick: **motiu**, with the catchy/repeated nature explained when the source explains it.
- chord chart in bass accompaniment: **full d’acords**, not a finger-position diagram. This contextual sense supplements the earlier generic Chart → Diagrama entry.
- Ukulele uses shipped catalogue **ukelele**. Bow: **arc**; frog: **nou**; stick: **vara**; hair: **crin**; chin rest: **barbada**; scroll: **voluta**; tailpiece: **cordal**; fine tuner: **microafinador**; down-/up-bow: **arc avall / arc amunt**. Bow changes are **canvis d’arc**, string crossings **canvis de corda**.
- **cent / cents** is the pitch-interval unit. This supersedes the inherited glossary's monetary-looking Cents → Cèntims for lesson authoring. No shipped UI table was changed by this author. Catalan reference evidence: [Enciclopèdia Catalana, sistemes d’afinació](https://www.enciclopedia.cat/gran-enciclopedia-de-la-musica/sistemes-dafinacio) uses *cent* as the musical interval unit. Bow **nou** is supported by [Enciclopèdia Catalana, arc](https://www.enciclopedia.cat/gran-enciclopedia-de-la-musica/arc); **barbada** by [TERMCAT Neoloteca](https://termcat.cat/es/neoloteca/ca/B?page=10&type=basic).
- Shared Up/Down: **Amunt / Avall**, neutral directions valid for pitch and picking strokes. The first/The second: **La primera opció / La segona opció** for gender-neutral choice reference across note/chord contexts. Either one: **Qualsevol**. Standalone shared count labels name abstract numerals (**Un, Dos, Tres…**) when counted nouns differ in gender.
- High 2/low 2: **2 alt / 2 baix**, describing finger position, not dynamic level. A short bend in the clarified comparison means **bend que queda baix**, not a short-duration bend. Violin level with floor means **paral·lel al terra**. Source 1700s is **el segle iniciat el 1700**, not its first decade, preserving the source digit group.
- Musical notation is not prose: retain note letters, chord symbols, p-i-m-a, CAGED, AABA and D/U strum-pattern symbols. Whole exact-source strings remain unapproved candidates with individual full-string reasons and stay empty in canonical TODO until independent approval.

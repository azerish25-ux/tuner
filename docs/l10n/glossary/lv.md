## 1. Locale decisions
- Locale/variant: lv, standard Latvian; Norwegian is Bokmål.
- Register: Formal plural jūs; polite plural imperatives. Short imperative actions; noun labels; third-person VoiceOver hints. Avoid reader-gender marking.
- Typography: sentence case, normal word spaces, no double or edge spaces. Curly apostrophe where needed; single ellipsis …. Quotes follow shipped table (Nordic ”…”/“…”; Baltic „…“/„…”; sw/zu “…”). Digits ASCII 0–9. Preserve line structure.
- Units: Hz, BPM, XP, ¢, A4 unchanged; cents = Centi. Minutes use existing minutes entry; seconds s, milliseconds ms on screen, full words in spoken hints.
- Notes: preserve inserted note names and all placeholders without inflecting them. No lesson note respelling. Accidentals follow existing note-name entries, never confuse with tuner direction: flat = par zemu; sharp = par augstu. Double accidentals repeat the musical alteration, not the direction word.
- Legal Settings path: Settings › Apple Account › Subscriptions. For languages without localized iOS system UI, retain the actual English path, not invented translated system menu labels. Apple’s iOS 26 language-support list excludes is/et/lt/lv/sw/zu; English system-path labels retained (https://images.apple.com/ie/iphone-16/specs/). In-app Settings retains Iestatījumi.
- Apple features: preserve product names Apple, iPhone, iPad, Apple Watch, App Store, Apple Music, Game Center, Siri; use shipped system labels, never invent product names. Home/Lock Screen and accessibility feature names require device verification when first encountered.
- Siri: natural imperative, retain ${applicationName} and every named token.
- Brands: Timbre, Timbre Pro, Pro, ChordPro unchanged and uninflected. Keep [G], ChordPro directives, URLs, ›, ·, ×, arrows and all format tokens verbatim.
- Musical tuning terminology overrides: the drone-training Intonation is pitch accuracy, not saddle adjustment. da/no/sv Temperament means musical temperament (not physical temperature); use Temperering / Temperering / Temperering respectively when this source occurs.

Use the instrument-name anchors for Guitar, Ukulele, Bass, Violin, Cello, Mandolin, Banjo. Songs equals the Songs tab. Ear Training/Rhythm reuse existing feature terminology; Music Theory/Singing and Originals/Standards & Classics are specified above. Songbook reuses the existing anchor. ## 4. Words that mislead
Tune: tuning verb/tab versus melody noun; use separate terms above. Sharp/flat: tuning too high/low versus musical accidental. Bar: musical measure, never pub or toolbar. Key: musical tonality, never password/keycap. Pick: plectrum or pluck, but choose in interface. Lock: confirmation of stable correct pitch, not a padlock; locked content is separate. Take: a recorded attempt. Run: streak or complete performance, not running. Chart: chord sheet/diagram except statistical plots in Progress. Intonation: pitch accuracy over a drone, not saddle setup. Next/Again/Slower: one term must work both on controls and as spoken commands, using shipped anchors. Practice: music practice, not professional business. Feel: haptic sensation, not emotion. Quest: optional side goal distinct from the Today activity set. Challenge: friend competition versus cumulative lesson test; translate by context. Finger numbers 1–4 and open 0 remain unchanged. Loop A–B labels are markers, not note names. For hammer-on/pull-off/slide/bend/vibrato use established guitar-teaching loanwords, not everyday translations; I–IV–V and V/I chord symbols remain intact.

### Instrument and technique decisions

- **hammer-on / pull-off**: retain the teaching loan terms inside Latvian prose, normally **hammer-on paņēmiens / pull-off paņēmiens** for standalone labels; definitions explain the fretting-finger tap and sideways release in Latvian. **slide / bend / vibrato** = **slaids / bends / vibrato**. Native musician terminology validation remains pending; these are not claimed as independently standardized.
- **quick change** (blues IV in bar two) = **agrā maiņa**; **boogie** = **bugi**; **comping** = **akordu pavadījums** or **svinga pavadījums**; **Charleston** = **čarlstons**.
- **major seventh chord** = **lielais mažora septakords**; **minor seventh chord** = **mazais minora septakords**; **dominant seventh** = **dominantseptakords**. Interval **major/minor seventh** = **lielā/mazā septīma**, not a chord.
- **triad / inversion / voicing / common tone** = **trijskanis / apvērsums / akorda salikums / kopējā skaņa**. **Dorian / Mixolydian** = **doriskā / miksolidiskā skaņkārta**.
- **texture / fill / tag** = **faktūra / iespēle / beigu frāze**. **country boom-chick** is described as **bass–akords**, with **bum / čak** sound syllables; **two-step** = **tūsteps**.
- Ukulele **re-entrant tuning** is provisionally **re-entrant skaņojums**, with the high fourth-string arrangement explained in Latvian. A reliable native pedagogical equivalent was not established; request a native musician decision, not automatic adoption of web-machine wording.
- Ukulele percussive **chunk** = **klikšķa pārvilkums**. Reggae/mandolin **chop** = **īsais akords** with immediate fretting-hand release; **backbeat** = **pretakcents**, always explained as beats two and four where the source does so. **skank**, **one-drop**, **highlife**, **lo-fi** remain genre/technique loans in translated prose pending terminology review.
- Electrical **pickup** = **skaņas noņēmējs**; musical **pickup** = **uztakts**. Bass **rest stroke** = **vilciens ar atbalstu**; **walking bass** = **soļojošais bass**; **chromatic approach notes** = **hromatiskās pieejas notis**.
- Bow **frog / stick / hair** = **rokturis / kāts / astri**; **scroll / fingerboard / chin rest / tailpiece** = **gliemezis / grifs / zoda balsts / stīgturis**; **fine tuners / endpin** = **smalkās skaņošanas skrūves / balsta kāja**. Distinguish neck (**kakliņš**) where necessary. **pizzicato** = **picikato**. Bow down/up strokes are **vilcieni lejup/augšup**, preserving the source's right/left guidance.
- **natural** in explicit pitch spelling = **bekars**; do not invent a ♮ absent from source. Violin **high two / low two** = **augstais / zemais otrais pirksts**, with source digits preserved where present.
- **slur** = **legato līga**; **tie** = **pagarinājuma līga**, or **salīgot** as a verb. The former joins articulation, the latter extends duration without a new attack. **triplet** = **triole**; **syncopation** = **sinkopēšana / sinkope**.
- Mandolin **course** = **stīgu kopa** and **pair** = **pāris**, never educational **kurss**. Tuning interference **beating** = **skaņas sitieni**, distinguished from rhythmic pulse in context.
- Banjo **drone string / head** = **burdona stīga / membrāna**. **roll** = **pirkstu raksts**, **alternating thumb roll** = **raksts ar īkšķi pamīšus**, **forward roll** = **pirkstu raksts uz priekšu**, **pinch** = **divu stīgu iesvārstījums**. **Clawhammer paņēmiens** retains the technical name and describes the relaxed curled hand and downward nail strike, not upward picking. Mandolin **crosspicking** = **šķērsspēle**, explained as repeating individual notes across three pairs. These descriptive choices need native-instrument review.
- Theory: **staff / space / ledger line** = **nošu līnijkopa / starplīnija / palīglīnija**; **treble / bass clef** = **vijoles / basa atslēga**. **authentic / plagal / half / deceptive cadence** = **autentiskā / plagālā kadence / puskadence / pārtrauktā kadence**.
- Singing **ah / loo** is rendered **ā / lū** to preserve the sung vowel, not the English spelling. **lip trill** = **lūpu trilleris**. Vocal strain/rest cautions are translated as supplied, not expanded into additional medical advice.

# Odia curriculum terminology alignment

This additive glossary records terminology adopted in independently reviewed lesson drafts. Original drafts and glossary are retained unchanged. This is linguistic guidance, not native rendering or pronunciation certification.

- Quarter note: କ୍ୱାର୍ଟର୍ ନୋଟ୍; half note: ହାଫ୍ ନୋଟ୍; whole note: ହୋଲ୍ ନୋଟ୍; eighth note: ଏଇଥ୍ ନୋଟ୍; sixteenth note: ସିକ୍ସଟିନ୍ଥ୍ ନୋଟ୍. Use these duration labels rather than fractional “ସ୍ୱର” wording that can imply pitch intervals.
- Dotted: ବିନ୍ଦୁଯୁକ୍ତ. Quarter rest: କ୍ୱାର୍ଟର୍ ବିରାମ; eighth rest: ଏଇଥ୍ ବିରାମ.
- Rhythmic “and”: “ଓ”, consistent with the existing rhythm curriculum. Keep literal numerical count sequences unchanged.
- Musical step (next scale note): କ୍ରମିକ ସ୍ୱର ଗତି or context-specific ସ୍କେଲ୍‌ର ପରବର୍ତ୍ତୀ ସ୍ୱର. Do not translate musical steps as physical ପାଦ. Actual foot, posture and foot-tapping references retain physical meanings.
- Major/minor/perfect interval qualities: ମେଜର୍ / ମାଇନର୍ / ପରଫେକ୍ଟ; interval numbers use ଦ୍ୱିତୀୟ, ତୃତୀୟ, ଚତୁର୍ଥ, ପଞ୍ଚମ, ଷଷ୍ଠ, ସପ୍ତମ. Octave: ଅକ୍ଟେଭ୍.
- Key versus tonic: use ଟୋନାଲିଟି where a sentence explicitly distinguishes the key system from its tonic/home note ମୂଳ ସ୍ୱର. Do not collapse chord, scale and key contexts into one shared meaning.
- Accidentals: ଶାର୍ପ / ଫ୍ଲାଟ୍ / ଡବଲ୍ ଶାର୍ପ / ଡବଲ୍ ଫ୍ଲାଟ୍; natural: ନ୍ୟାଚୁରାଲ୍. Tuner too-high/too-low readings are not accidental names.
- Dynamics: soft/gentle concerns loudness or effort, not automatically slow tempo. Use ମୃଦୁ / ହାଲୁକା as context requires.
- Source “1700s” or “1800s” spanning a century must not become a single decade. Preserve the original digits while expressing the century, e.g. “1700 ମସିହାରୁ ଆରମ୍ଭ ହୋଇଥିବା ଶତାବ୍ଦୀର”. Native layout must verify longer titles.
- Preserve original Western note/chord/solfège notation in exercises. Every exact-source identity still requires its own source-bound independent review decision; this paragraph is not a blanket exemption.

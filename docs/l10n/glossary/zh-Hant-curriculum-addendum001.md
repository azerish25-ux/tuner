# Traditional Chinese glossary addendum — reviewed wording alignment

Companion to the original glossary; does not replace or alter immutable review artifacts.

- **Drop D / Drop A** preset labels: **低音弦降至 D / 低音弦降至 A**. Do not write 降 D / 降 A, which names flat notes instead of drop tuning. These labels already occur in the independently accepted UI v4.
- **Major/minor** must distinguish chord quality (**大和弦 / 小和弦**) from key/mode (**大調 / 小調**). Seven deduplicated Learn source keys currently mix these contexts and are held for source-key separation; no globally chord-specific wording is accepted for those mixed keys.
- Offbeat spoken **and**: **又**. Ordinary conjunction “and” remains 和/與 as grammar requires. Reviewed curriculum corrections bind exact rows; this is not a blanket text replacement.
- Named **Originals** destination: **原創歌曲**.
- **Mini F**: **簡易 F**.
- **Three-chord** describes three separate chords (**三個和弦**), not a triad (**三和弦**).
- **Skip to My Lou**: retain the canonical traditional song title, with a per-key independent proper-name decision, rather than the unsupported literal title 跳向我的露. References use the same title.
- **1700s / 1800s**, where the source means a century, must not be reduced to the opening decade. Current source-bound wording preserves numeric source tokens while explicitly saying 世紀; the digits are technical validation constraints, not permission to change the chronology.

This addendum records accepted reviewed decisions and a clearly unresolved source-context blocker. Native rendering, accessibility pronunciation, and screenshot QA remain pending.

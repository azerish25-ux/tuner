# Malay localization glossary — draft for independent review

Canonical locale: `ms`; standard Malaysian Malay, Latin script, left to right. Use warm, direct `anda` consistently; gender-neutral. Buttons use short verbs (`Mula`, `Main`, `Simpan`); instructions use clear imperatives without artificial politeness. Sentence case, normal Latin spacing, curly quotation marks “…” only where needed, apostrophe ’, ellipsis … . Literal digits stay ASCII; format tokens are unchanged. Cardinal plurals use `other` only. No native-speaker certification is claimed.

## Brand and notation
Timbre, Timbre Pro, Pro, Apple, iPhone, iPad, Apple Watch, App Store, Apple Music, Game Center, Siri, ChordPro, XP, BPM, Hz, A4 and ¢ remain unchanged. Notes/chords C, F♯, B♭, Em, G7 etc. retain canonical notation. Preserve syntax `[G]`, `{start_of_chorus}`, `${applicationName}`, every format placeholder and music numeral. Original sung lyrics, filenames and English App Review notes are outside translation scope; surrounding lesson prose is not exempt.

## Platform and grammar
Use Seting › Akaun Apple › Langganan in billing text. Home Screen = Skrin Utama; Lock Screen = Skrin Kunci; widget = widget; Live Activity = Aktiviti Langsung; Shortcuts = Pintasan; Control Center = Pusat Kawalan; Family Sharing = Perkongsian Keluarga. Platform terminology needs independent verification, not claimed device review.

VoiceOver hints describe action (`Membuka…`, `Memainkan…`); labels omit control types absent from source. Avoid attaching morphology to unknown placeholders. Siri commands use natural imperatives and retain `${applicationName}`. Lesson ASCII digits, line breaks, sharp/flat glyph counts and music symbols must match source. Quoted controls use their exact fixed names. No invented acoustic or recording claims.

## Curriculum consistency addendum
Consistency choices independently reviewed and applied: whole note = semibrif; half note = minim; quarter note = krocet; eighth note = kuaver; sixteenth note = semikuaver. Fractions of a beat remain setengah/suku detik; bow-length fractions remain separuh bow. Six-eight meter is enam-lapan, not six separate quarter-note beats. Power chord consistently kord kuasa; pickup before the first bar anakrusis. Soft dynamics = lembut, slow tempo = perlahan. Generic Originals category = Lagu asli; attribution brand Timbre Original/Originals unchanged.

Original work/song titles and composer names remain recognizable; surrounding historical/teaching prose is localized. Sung lyric anchors (including quiz choices quoting exact sung words) remain in the performed language as required by translation guide, not general English UI fallback. Explicit per-key independent invariant evidence is required. Full author title decision map lives outside snapshot at ms-drafts/song-title-decisions-all.json pending final integration.

## 1. Locale decisions
- Locale/variant: lt, standard Lithuanian.
- Register: Formal plural jūs; polite plural imperatives. Short imperative actions; noun labels; third-person VoiceOver hints. Avoid reader-gender marking.
- Typography: sentence case, normal word spaces, no double or edge spaces. Curly apostrophe where needed; single ellipsis …. Quotes follow shipped table (Nordic ”…”/“…”; Baltic „…“/„…”; sw/zu “…”). Digits ASCII 0–9. Preserve line structure.
- Units: Hz, BPM, XP, ¢, A4 unchanged; cents = Centai. Minutes use existing minutes entry; seconds s, milliseconds ms on screen, full words in spoken hints.
- Notes: preserve inserted note names and all placeholders without inflecting them. No lesson note respelling. Accidentals follow existing note-name entries, never confuse with tuner direction: flat = per žemai; sharp = per aukštai. Double accidentals repeat the musical alteration, not the direction word.
- Legal Settings path: Settings › Apple Account › Subscriptions. For languages without localized iOS system UI, retain the actual English path, not invented translated system menu labels. Apple’s iOS 26 language-support list excludes is/et/lt/lv/sw/zu; English system-path labels retained (https://images.apple.com/ie/iphone-16/specs/). In-app Settings retains Nustatymai.
- Apple features: preserve product names Apple, iPhone, iPad, Apple Watch, App Store, Apple Music, Game Center, Siri; use shipped system labels, never invent product names. Home/Lock Screen and accessibility feature names require device verification when first encountered.
- Siri: natural imperative, retain ${applicationName} and every named token.
- Brands: Timbre, Timbre Pro, Pro, ChordPro unchanged and uninflected. Keep [G], ChordPro directives, URLs, ›, ·, ×, arrows and all format tokens verbatim.
- Musical tuning terminology overrides: the drone-training Intonation is pitch accuracy, not saddle adjustment. da/no/sv Temperament means musical temperament (not physical temperature); use Temperering / Temperering / Temperering respectively when this source occurs.

## 3. Course and song names
Use the instrument-name anchors for Guitar, Ukulele, Bass, Violin, Cello, Mandolin, Banjo. Songs equals the Songs tab. Ear Training/Rhythm reuse existing feature terminology; Music Theory/Singing and Originals/Standards & Classics are specified above. Songbook reuses the existing anchor. Lyric credits retain names and years, translating only connecting words; lyrics are not translated.

## 4. Words that mislead
Tune: tuning verb/tab versus melody noun; use separate terms above. Sharp/flat: tuning too high/low versus musical accidental. Bar: musical measure, never pub or toolbar. Key: musical tonality, never password/keycap. Pick: plectrum or pluck, but choose in interface. Lock: confirmation of stable correct pitch, not a padlock; locked content is separate. Take: a recorded attempt. Run: streak or complete performance, not running. Chart: chord sheet/diagram except statistical plots in Progress. Intonation: pitch accuracy over a drone, not saddle setup. Next/Again/Slower: one term must work both on controls and as spoken commands, using shipped anchors. Practice: music practice, not professional business. Feel: haptic sensation, not emotion. Quest: optional side goal distinct from the Today activity set. Challenge: friend competition versus cumulative lesson test; translate by context. Finger numbers 1–4 and open 0 remain unchanged. Loop A–B labels are markers, not note names. For hammer-on/pull-off/slide/bend/vibrato use established guitar-teaching loanwords, not everyday translations; I–IV–V and V/I chord symbols remain intact.

## 5. Lesson author decisions (2026-10-26; not independent review)
- Keep the UI register: polite plural imperatives (grokite, klausykitės, laikykite), concise neutral titles.
- Preserve all source note letters and chord symbols, even where Lithuanian schools use H or solfège. Write spelled-out sharp/flat as diezas/bemolis; do not insert accidental glyphs when absent.
- Intervals: second = sekunda, third = tercija, fourth = kvarta, fifth = kvinta, sixth = seksta, seventh = septima; major/minor interval = didysis/mažasis, not mažorinis/minorinis. Finger ordinals explicitly refer to pirštas.
- Fretted instruments: fret = skirsnis; open string = laisva styga; pick = mediatorius; pluck = užgauti stygą; strum = braukti per stygas; neck = grifas.
- Rhythm: beat = dūžis in counting/playback; bar = taktas; rhythmic subdivision = padala; downbeat = pirmoji takto dalis.
- Technique: hammer-on = užkalimas, pull-off = nuplėšimas, bend = stygos tempimas, slide = slydimas, vibrato = vibratas; explain techniques naturally rather than treating ordinary English as an invariant.
- Song titles remain their original names consistently, including in prose; explanatory subtitles are translated. Bare original titles, note notation, proper-name credits, and the established term Solo are only proposed exact-source candidates, not self-approved exemptions.
- Guitar E A D G B E mnemonic is adapted to „Eglė Augina Daug Gražių Baltų Eglių“, retaining initial letters in exactly that order; this changes the mnemonic example, not the notes taught.
- Source-identical candidates remain empty in the canonical TODO and appear with individual reasons in author outputs and the review payload.

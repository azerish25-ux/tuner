# Timbre glossary — th

Status: AI-authored and AI-reviewed terminology decisions, 2026-10-25. Not human/native-speaker approved. Legal/device wording and layout still need native/device QA. Overrides take precedence over inconsistent legacy anchors.

## 1. Locale decisions
- Locale/variant: th; standard modern written language; zh-CN means mainland Simplified Chinese, ja Japan, ko South Korea, th Thailand, vi Vietnam, id Indonesia.
- Register: neutral, no gendered polite particles. Warm teacher voice, no embellishments.
- Buttons: compact action phrases or established nouns; instructions polite and direct. Gender-neutral constructions throughout.
- Quotation/punctuation: “…”; no full stops, no spaces between words, spaces between phrases; no zero-width characters.
- Apostrophe: ’ where needed; ellipsis always …. No added exclamation marks.
- Digits: ASCII 0–9; preserve all literal numbers; runtime values use locale formatting.
- Units: Hz, BPM, XP, ¢, A4 unchanged; other units in the terminology table.
- Capitalization: sentence case where applicable; preserve brand capitalization.
- Interface notes: supplied by placeholders; do not invent note names. Lesson notes/chords: preserve C, B, F♯, B♭, Em, G7 and all signs exactly.
- Accidentals (sharp / flat / double sharp / double flat): ชาร์ป / แฟลต / ดับเบิลชาร์ป / ดับเบิลแฟลต; direction is a separate row below.
- Legal Settings path: การตั้งค่า › บัญชี Apple › การสมัครรับ. Preserve › and every renewal/cancellation fact.
- Apple feature names (Home, Lock, widget, Live Activity, Shortcuts, Control Center, Family Sharing, Haptics): หน้าจอโฮม / หน้าจอล็อค / วิดเจ็ต / กิจกรรมสด / คำสั่งลัด / ศูนย์ควบคุม / การแชร์กันในครอบครัว / การสั่น.
- Siri: short spoken commands; preserve all ${applicationName} and other tokens. Next/Again/Slower must work both on screen and aloud.
- Unknown placeholders: no sound-dependent affixes; use noun adjacency or labels. All arguments and positions preserved.
- Plurals: other only.

## 4. Sense distinctions
Tune verb/tab ≠ tune melody; direction flat/sharp ≠ accidentals. Bar means measure, never pub or UI bar. Key means tonality, not keyboard/password. Pick means plectrum/pluck/choose by context. Lock means stable correct pitch, not padlock. Take means recorded performance attempt, not taking a lesson. Run means streak or continuous performance, not running. Chart means chord notation unless explicitly a progress graph. Intonation means playing/singing accurately over a drone, never saddle or octave adjustment (legacy ja/zh-CN entries are overridden above). Practice means musical practice, not a professional office. Feel means haptic feedback, not emotion. Challenge-friend and unit challenge use the separate senses above.

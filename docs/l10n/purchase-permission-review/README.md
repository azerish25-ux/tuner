# Purchase and permission wording review

All 1,104 target rows (23 current keys in 48 locales) were independently back-translated without English source access, then compared with English and actual source contexts. Original target-only evidence is preserved under `docs/l10n/staged/blind-backtranslation`.

Two exact-old-guarded deadline corrections were applied: German exclusive before-day wording and Lithuanian before-day-begins wording. All other 1,102 rows were retained after contextual review. `corrections.json` records the pre-application proposals; `applied-corrections.json` is the application receipt. Snapshot hashes and row dispositions describe the reviewed pre-correction targets, not the post-fix file bytes.

This is AI linguistic QA, not native/human certification, legal advice, compliance review or actual-device verification. Blinded ambiguity notes were not automatically treated as translation defects.

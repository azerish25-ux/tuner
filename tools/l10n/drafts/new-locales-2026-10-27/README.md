# New UI locales — reviewed text checkpoint

Traditional Chinese (`zh-Hant`), Malay (`ms`), and Odia (`or`): 1,980 UI keys each, 5,940 total. The seven plural keys per language are counted as keys, not leaf variants; see the manifest for leaf counts.

These are **draft data, not shipping resources**. Independent model linguistic review was performed, including a separately blinded 23-row legal/permission scope per locale, followed by source-aware correction review. This is not native-speaker, legal, privacy-implementation, runtime, typography, VoiceOver, device, App Store, or Apple approval certification.

No `Learn.strings` curriculum translations are included: that separate 6,083-key-per-language work remains in progress. No locale inventory, fallback mapping, source code, CI workflow, or resource bundle is changed here. Existing 49-language / 98-image Watch evidence does not establish the future 52-language / 104-image scope.

The JSON files contain exact accepted targets from the bound UI review snapshots. Source/target bindings use explicit canonical JSON hashing. Review evidence exports remove environment paths and agent identifiers; each keeps the immutable upstream artifact hash, and the manifest records original review input and lineage hashes. Export hashes differ from originals because of those redactions. Original review records were not overwritten.

The Malay snapshot is the accepted v4 UI baseline; later cross-curriculum terminology revisions, if accepted, require a subsequent guarded checkpoint. Glossaries are companion drafts; later glossary work does not silently alter these frozen targets. Intentional unchanged brand names, canonical music notation, and platform tokens are not blanket English fallback permissions.

Integration remains blocked on final full-scope translation/review, resource validation, locale alias/plural wiring, new locale native screenshots and VoiceOver/layout checks, and the expanded Watch capture matrix. Pricing stays country-based, independent of language.
